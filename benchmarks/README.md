# 证链联研基准集

## `evidence_seed_v0.1.jsonl`

这是用于打通评测管线的合成种子集，不包含真实用户数据，也不是已完成的人工金标准。
每一行是一个独立 JSON 对象，包含：

- 输入 Claim、来源元数据和来源片段；
- 来源完整性、证据等级、冲突状态的预期标签；
- 标签理由；
- `review_status=draft-machine-authored`，表示仍需人工盲审。

任何准确率只能表述为“合成种子集基线”，不得写成真实应用准确率。当前团队决定不把
人工复核该合成集作为用户任务；本数据只用于程序回归。后续真实来源样例由系统保存
DOI/URL和精确定位，并与合成集分开报告。如未来引入外部人工标注，应发布新版本文件，
保留本文件和变更记录，不覆盖原始标签。
