## 视频优先流程

1. 打开抖音视频或推荐流，开始播放，点击工具栏证链图标。优先从当前播放项的公开编号或话题链接定位原视频，其次使用/video/编号或modal_id；无法绑定具体编号时不猜测。
2. 点击“分析并核验当前视频”。采集约30秒的当前标签页声音、最多6帧可见画面及可取得的字幕片段，裁剪后发送给图像模型。保持当前标签、窗口和视频位置；暂停视频只取得一帧，循环回放时结束当前段采样。
3. 结合声音转写，自动提取最多3项核心事实主张；背景年份、队名、弹幕和纯观点不默认查证。然后，然后自动启动外部检索核验，无需手动输入和勾选。没有明确主张时停止，不编造主张。原视频片段观察、链接和采样位置仍可查看。
4. 手动输入放在“补充或修改主张（可选）”。旧的已完成观察可点击“自动核验已提取的主张”继续，不必重复采样。重新打开侧栏恢复同一任务，不自动创建重复核验。
5. 如只想核验文字，明确勾选“这次只核验输入文字，不分析原视频”。这条路径不宣称读取了视频。

切换视频后重新读取。旧视频观察不能自动用于当前视频。弹幕和字幕保留；与视频重叠的小型输入栏在上传前遮盖，无需关闭弹幕。登录弹窗、密码框或大面积编辑框遮挡时停止采集；窗口或遮盖区域变化也停止采集。不把整页截图上传。

## 能力边界

分析当前播放位置附近约30秒的声音与稀疏画面，不下载完整视频。标签页声音交给私有服务器本地Whisper small int8转写，再与画面结合分析。转写可展开查看；无语音或识别失败会明确显示。

视频主要观点、核心事实核验与视频真伪鉴定分别处理；当前不提供视频真伪鉴定结论。图像分析使用现有DeepSeek账号和共同模型额度，没有扩大额度。

仅主动操作时读取，无常驻扫描、浏览历史、摄像头或麦克风权限；新增tabCapture/offscreen权限仅用于主动采集当前标签页声音，最多35秒后释放；正式manifest没有all_urls权限。凭证只在浏览器会话内保存，不在ZIP中。侧栏关闭可恢复原任务；浏览器完全退出后需重新导入凭证。

原始采样保存在浏览器当前任务及服务器私有目录，作品材料只使用脱敏摘要。
