## 用户侧（需要真人完成）

### 第一次登录梧桐后，请核对

- [ ] 登录是否成功，账号是否要求实名认证或组织认证。
- [ ] “创建智能体/注册智能体”的入口名称和所在页面。
- [ ] 创建页面的全部字段名、必填标记、字数/格式限制。
- [ ] 是否可先存草稿，提交审核后哪些字段仍可修改。
- [ ] AIC 在创建、提交还是审核通过后生成。
- [ ] EAB、证书或下载入口出现的准确时机。
- [ ] 是否有团队、协作者或项目成员功能。
- [ ] 是否显示调用量、访问量、日志或审核状态。

### 可以安全回传给技术侧

- 页面截图（先遮住手机号、邮箱、姓名、组织编号等个人信息）。
- 字段名称、选项、校验提示、审核说明和公开文档链接。
- 脱敏后的错误提示、请求时间和操作步骤。

### 不要发送或提交到仓库

- API Key、Token、Cookie、密码、短信验证码。
- 私钥、完整客户端证书、`.env` 文件。
- 身份证件、未脱敏账号信息或其他参赛者的个人资料。
