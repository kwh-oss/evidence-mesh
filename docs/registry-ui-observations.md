# 梧桐 Registry 登录态页面观察

观察日期：2026-09-23  
来源：用户提供的登录态页面截图  
页面：`ACPs智能体注册` → `我的智能体`  
准确地址：`https://wt.ioa.pub/registry/#/my-agents/index`

> 边界说明：该站点是梧桐 ACPs Registry，不是智能体创建/编排平台。“注册新智能体”
> 是登记智能体元数据与 ACS 的表单，不能据此认定它负责创建智能体业务逻辑。

## 截图直接证据

- 已进入“我的智能体”后台，页面显示用户头像和账号名称。
- 当前账号下智能体数量为 0，列表显示“暂无数据”。
- 页面提供“注册”和“删除”操作。
- 查询条件包括：名称、版本、状态、类型。
- 列表字段包括：图标、名称、版本、能力描述、类型、状态、提交时间、处理时间、
  处理意见、操作。
- 页面提供“访问开源社区”“基础设施访问入口”“关于可信注册”三个入口。

## Registry“注册新智能体”元数据表单

第二张截图显示的表单字段如下：

| 字段 | 页面标记 | 当前可确认的信息 |
|---|---|---|
| 图标 | 无红色星号 | 通过加号区域上传；尺寸、格式和大小限制尚未显示 |
| 名称 | 必填 | 单行文本框；未显示字符限制或唯一性规则 |
| 版本 | 必填 | 单行文本框；未显示版本号格式规则 |
| 能力描述 | 无红色星号 | 多行文本框；未显示字数限制 |
| 是否可派生（本体） | 未见必填标记 | “否/是”二选一，默认截图中选择“否”，旁有帮助图标 |
| ACS | 无红色星号 | 多行文本框；占位提示要求输入 JSON 格式的 ACS（Agent Capability Specification） |

表单底部只有“保存”和“取消”两个按钮。截图没有显示“保存”究竟只是生成草稿，还是
会创建注册记录或进入审核流程，因此当前不得把“保存”等同于无副作用的草稿操作。

## 可以合理推断但尚未验证

- Registry 支持一个账号管理多个智能体记录。
- 注册记录存在审核/处理流程，因为列表包含状态、提交时间、处理时间和处理意见。
- 删除操作可能要求先选择记录；未进行点击验证。

## 仍需核对

- 图标、名称、版本和能力描述的字符或文件格式限制。
- 智能体类型选项、状态选项及其准确含义。
- 是否支持保存草稿、提交前预览、提交后修改。
- AIC 的生成时机。
- ACS 的填写或上传方式。
- 服务地址、健康检查、协议端点和图标要求。
- EAB、mTLS 证书和基础设施入口之间的关系。
- “是否可派生（本体）”帮助提示的官方解释。
